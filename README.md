# Mercadinho Alegria

Site demonstrativo de mercado, criado para um projeto escolar de Jovem Programador (Senac).

## Páginas
- `index.html` — página inicial
- `produtos.html` — catálogo com busca por nome
- `ofertas.html` — ofertas demonstrativas
- `sobre.html` — apresentação do mercado
- `cadastro.html` — formulário de cadastro demonstrativo
- `style.css` — cores, layout e responsividade
- `script.js` — busca de produtos e validação do formulário

## Como abrir
Abra `index.html` no navegador. Para editar, abra a pasta inteira no Visual Studio Code.

## Publicar com GitHub Pages
1. Crie um repositório no GitHub, por exemplo `mercadinho-alegria`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No repositório, entre em **Settings** → **Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde alguns minutos e abra o endereço mostrado na seção Pages.

## Observações
- As imagens vêm de URLs externas do Unsplash e precisam de internet para carregar.
- Os preços, endereço e telefone são ilustrativos.
- O formulário é apenas uma demonstração: não envia dados para um servidor e não armazena cadastro. Não use senhas reais.
